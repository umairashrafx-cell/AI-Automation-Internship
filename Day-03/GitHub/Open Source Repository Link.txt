https://github.com/enescingoz/awesome-n8n-templates

Why this repo:
- Directly on-topic for the internship (n8n workflow templates, AI agents, RAG chatbots).
- Actively maintained, explicitly welcomes PRs that add new template JSON files to the
  appropriate category folder.
- Low-friction, genuine "meaningful improvement": contribute the Day-03 Lead Management
  workflow (Lead_Management_Workflow.json) as a new template under a CRM/Lead-Gen category,
  plus a short README entry describing it.
