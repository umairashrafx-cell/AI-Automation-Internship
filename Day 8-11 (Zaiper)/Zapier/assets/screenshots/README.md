# Screenshots

Drop your build screenshots here and link them from the module READMEs.

Suggested naming so they sort and read well:

```
01-lead-intake-form.png
01-lead-intake-table.png
01-lead-intake-zap.png
01-lead-intake-test-run.png
02-expense-portal-form.png
02-expense-paths.png
...
09-ops-report-email.png
```

Worth capturing for each module:

- The **Interface / form** as a submitter sees it
- The **Table** with a few real rows in it
- The **Zap editor** showing the full step list
- A **successful test run** in Zap History — this is the one that proves it works
- For the Kanban modules, the **board** with cards in different columns
- For the chatbot and agent modules, a **real conversation** including the edge case (unavailable slot, refused question, escalation)

Link them from a module README like this:

```markdown
![Lead intake form](../assets/screenshots/01-lead-intake-form.png)
```
