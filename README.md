# AI-Automation-Internship

Repository for the MATalogics AI Automation No-Code & Lo-Code System Engineering Internship (April Batch).

Each day's task lives in its own folder: `Day-01/`, `Day-02/`, `Day-03/`, and so on. Every folder contains the working files (n8n workflows, Postman collections, screenshots, and a report) for that day's assignment.

## Day-03: Git & GitHub + Postman + APIs

Folder: [`Day-03/`](./Day-03)

Built a single n8n workflow exposing a Lead Management REST API (Create / Get All / Update / Delete lead), backed by Google Sheets, plus the matching Postman collection used to test each endpoint.

- **GitHub** — open-source contribution links and screenshots: [`Day-03/GitHub/`](./Day-03/GitHub)
- **Postman** — collection + environment: [`Day-03/Postman/`](./Day-03/Postman)
- **n8n** — Lead Management workflow: [`Day-03/n8n/`](./Day-03/n8n)
- **Google Sheets** — data store link + screenshot: [`Day-03/Google Sheets/`](./Day-03/Google%20Sheets)
- **Report** — Day-03 Report.docx: [`Day-03/Report/`](./Day-03/Report)
